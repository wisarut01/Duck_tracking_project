## Storybook นี้มีอะไร

- **Design Tokens** — สี light/dark, sticky pastels, type scale, radius, shadow, การ map type/status/priority
- **Primitives** — Button, Input, TextArea, Select, Badge, Avatar(+Group), Modal, Tooltip, Toast, EmptyState, Skeleton
- **Domain** — IssueTypeIcon, PriorityIcon, StatusPill, IssueCard, BoardColumn, KanbanBoard, IssueDetailPanel, CreateIssueModal, IssueMentionChip, SearchBar, CommandPalette
- **Docs** — PageTree, MarkdownView, PageEditor, LinkedIssuesPanel
- **Layout** — Sidebar, TopBar, AppShell
- **Screens** — Login, ProjectBoard, IssueDetail, DocsPage, SearchResults

## วิธีใช้

- **สลับธีม**: ปุ่ม 🖌 (Theme) บน toolbar ด้านบน → `light` / `dark`
- **Accessibility**: แท็บ *Accessibility* ด้านล่างของแต่ละ story (axe-core)
- **Controls**: ปรับ props สดๆ ในแท็บ *Controls*
- **Actions**: event เช่น `onMoveIssue` จะขึ้นในแท็บ *Actions*

## หลักการออกแบบ (สั้นๆ)

- **Canvas อุ่น ไม่ใช่ขาวจั๊วะ** — พื้น off-white + dot-grid บนพื้นที่แบบ board
- **เหลืองเดียว** — `brand` ใช้กับ action หลัก / สิ่งที่ active เท่านั้น
- **Sticky pastel = หมวดหมู่** — ฟ้า Task, ชมพู Bug, เขียว Story
- **สีไม่เคยมาเดี่ยว** — ทุกสีมีไอคอน + ข้อความคู่กันเสมอ
- **มุมมน เงานุ่ม ตัวหนาเป็นมิตร** — Plus Jakarta Sans + IBM Plex Sans Thai
